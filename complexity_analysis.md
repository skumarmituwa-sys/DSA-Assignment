# Complexity Analysis

## Merge Sort
- Best case: O(n log n)
- Average case: O(n log n)
- Worst case: O(n log n)
- Additional space: O(n)
- For this input: 3 merge passes and 17 comparisons (for the given implementation).

## Quick Sort
- Best case: O(n log n)
- Average case: O(n log n)
- Worst case: O(n^2)
- Additional space: O(log n) average recursion stack; O(n) worst case.
- For this input: 5 partitions and 16 comparisons (for the given Lomuto implementation).

The exact comparison count depends on implementation and pivot selection.
